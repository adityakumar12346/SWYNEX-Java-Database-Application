# Book Inventory Management System

A Java-based Book Inventory Management System developed using **Java, MySQL, and JDBC** as part of my SWYNEX Technologies internship.

### Features
- Add and view books
- Search books
- Update book details
- Delete books
- MySQL database connectivity
- Input validation and exception handling

### Technologies Used
- Java
- MySQL
- JDBC
- MySQL Workbench
- VS Code

Developed as part of **SWYNEX Technologies – Task 3**.
